# Extensão Profits Scraper

## Como instalar
1. Vá em `chrome://extensions`
2. Ative "Modo do desenvolvedor" (canto sup. dir.)
3. Clique "Carregar sem compactação"
4. Selecione a pasta `extensao-scraper`

## Como usar pra ler site inteiro
1. Abra https://app.profitsbet.co/sign-in
2. Clique no ícone da extensão > "Ler site inteiro agora"
3. Navegue pra /sign-up, /forgot-password, logado no dashboard, e clique de novo em cada página
4. Clique "Exportar dados (JSON)" -> vai baixar `profits-scrape-....json` com HTML/CSS/seções/cores de cada rota
5. Me envie esse JSON ou deixe em `app1k/` que eu uso pra clonar 100% cada nova seção que ainda não clonamos

Também tem botão "Tirar print full-page" pra comparar pixel a pixel.

> Dica foda: se o cliente pedir mais páginas internas (carteira, jogos), é só navegar logado e clicar em ler -> já clono em minutos.
